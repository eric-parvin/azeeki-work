The active resume workflow is under `resume-bank/`.

- Edit `resume-bank/build.js` for the master and five targeted resumes.
- Edit `resume-bank/capability.js` separately for the consulting capabilities statement.
- Treat all DOCX, Markdown, TXT, and PDF files as generated outputs.

## Legacy Process

The files under `source/` belong to the earlier Markdown-first/Pandoc design. Do not update both systems. Archive or remove the legacy files only after the `resume-bank` scripts have been repaired and a clean local rebuild reproduces all approved outputs.

Keep this repository private because the resume content includes personal contact information and named customer work.
