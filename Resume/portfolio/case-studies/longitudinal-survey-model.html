Year-over-year analysis when the questions keep changing

Client Academic medical center Role Semantic model architect Scope Model design and validation

Problem

An academic medical center analyzed results from a national annual survey administered to its graduating students. The institution wanted multi-year trend analysis and benchmark comparison against peers.

The complication was structural. Every survey cycle, questions were reworded, renumbered, added, retired, or moved between sections. A question that was item 12 one year might be item 15 the next, with slightly different phrasing. Sometimes the wording change was cosmetic. Sometimes it altered what was actually being asked.

Reporting keyed on question number produced trend lines that silently compared different questions across years. Reporting keyed on question text broke whenever wording shifted. Both approaches looked fine on the surface and were unreliable underneath.

This is a modeling problem disguised as a reporting problem. No amount of report-layer cleverness fixes a model that cannot express "this question in 2024 is the same question as that one in 2022."

Approach

The model needed to hold two truths at once: the exact form a question took in a given year, and the continuing concept that persists across years.

  • Separated question concept from question version, so each year's specific wording and numbering was preserved while trend analysis worked against the stable concept.
  • Built version-aware keys uniquely identifying a question as it appeared in a particular cycle, with explicit mapping to its conceptual lineage.
  • Designed conformed dimensions for question groups and sections so navigation stayed consistent even as the survey reorganized.
  • Modeled benchmark mapping separately, since peer comparison data followed its own structure and versioning.
  • Wrote SQL validation queries reconciling report output against source data as a standing practice, not a one-time check.

Solution

  • A semantic model with distinct question-version and question-concept structures, letting the same report answer "what did students say in 2024" and "how has this changed since 2019."
  • Rating and response structures handling the survey's various answer scales without collapsing meaningful distinctions.
  • Benchmark mapping enabling peer comparison alongside internal trends.
  • A validation query set proving report figures matched source data — run as part of each refresh cycle rather than trusted by default.
  • Documentation of which comparisons were analytically valid and which were not, so report consumers understood the limits of the data.

Outcome

  • Longitudinal comparison became defensible. Trend analysis compared genuinely equivalent questions, and where equivalence did not hold, the model made that visible rather than hiding it.
  • Report figures reconciled to source. Validation queries gave the team a repeatable way to confirm the numbers, which mattered for analysis informing accreditation and curriculum decisions.
  • The model absorbed future change. Subsequent survey cycles could be added without restructuring, because versioning was designed in rather than patched around.
  • Analytical limits were documented. Consumers knew which comparisons the data supported — as valuable as the comparisons themselves.
